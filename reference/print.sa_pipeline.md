# Print method for SA pipeline tables

Custom print method for sa_pipeline objects that provides a clean
display of the pipeline with optional highlighting of issues.

## Usage

``` r
# S3 method for class 'sa_pipeline'
print(x, ...)
```

## Arguments

- x:

  An sa_pipeline object (from get_sensitivity_pipeline())

- ...:

  Additional arguments passed to print.data.frame

## Value

Invisibly returns the input object
