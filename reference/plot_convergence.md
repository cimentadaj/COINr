# Convergence plot of SA results

Quick plot of the convergence of the SA results. Only works if
`monitor_convergence = TRUE` was specified when running
[`get_sensitivity2()`](https://bluefoxr.github.io/COINr/reference/get_sensitivity2.md).

## Usage

``` r
plot_convergence(SA_res)
```

## Arguments

- SA_res:

  Output list from
  [`get_sensitivity2()`](https://bluefoxr.github.io/COINr/reference/get_sensitivity2.md)

## Value

A plot
